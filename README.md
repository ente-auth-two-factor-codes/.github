## Troubleshooting Common Issues

Install issues? Verify the device clock is automatic; TOTP codes fail when the clock drifts.  
Performance problems? Restore from the encrypted backup before assuming codes are lost.  
License/activation? Keep the recovery key separate from the app installation.  
Compatibility? Re-add a code if it was typed from a secret with missing characters.  
Update failures? Update the app after a major OS release that changes secure storage.
